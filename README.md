# Biodata Portfolio Studio
Web aplikasi portofolio dan form biodata modern yang dirancang dengan antarmuka bersih berbasis gaya Bento Grid dan Glassmorphism.

## Fitur Utama
- Desain responsif dengan gaya Bento Grid & Glassmorphism.
- Navigasi profil dan informasi biodata interaktif.
- Tata letak modern menggunakan HTML5 dan CSS kustom.

## 🛠️ Teknologi yang Digunakan
- HTML5
- CSS
- Javascript
- Git & GitHub

## 🚀 Cara Menjalankan
1. Clone repository ini:
   \`git clone https://github.com/arnyynarn/BiodataUI.git\`
2. Buka file \`index.html\` langsung melalui browser pilihan Anda, atau gunakan Live Server di VS Code.
